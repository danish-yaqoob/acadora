# Changelog

## 0.2.0 — 2026-11-18

- Added English/Simplified Chinese language selection in onboarding and Settings, with localized navigation, forms, actions, dates, accessible labels, and notifications.
- Preserved language preferences through refresh, offline use, and JSON backups. Database version 2 safely migrates existing profiles; older backups default to English.
- Kept user-created academic content and stored task enum values unchanged across languages.
- Added version display and step-by-step README instructions for cloning, ZIP installation, npm/pnpm development, production preview, offline installation, and updating a local checkout.
- Added translation, migration, legacy-backup, and Chinese/English browser regression coverage.

## 0.1.0 — 2026-11-17

Initial local-first release candidate: responsive workspace, onboarding, courses, task management, study planner, academic calendar, timestamp focus timer, study analytics, Markdown notes, preferences, JSON backup/restore, CSV/Markdown exports, PWA offline caching, and release documentation.

No backend, account, advertising, telemetry, paid API, or remote synchronization. See README for timing, date-distribution, multi-tab, localization, and accessibility limitations. Publication remains a separate user action.
