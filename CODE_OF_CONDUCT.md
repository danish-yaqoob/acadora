# Community Code of Conduct

Everyone should be able to learn and contribute without harassment, discrimination, intimidation, or unwanted attention. Be respectful across languages, cultures, institutions, identities, and experience levels. Critique ideas constructively. Respect privacy and do not publish another person's academic or personal information.

Maintainers may edit or remove harmful content, close discussions, limit participation, or remove contributors depending on severity and repetition. Decisions should be proportionate and give affected participants a chance to explain when appropriate. Report community problems to repository maintainers using GitHub's reporting tools; avoid exposing private information in public issues. A dedicated private reporting contact should be added when maintainership is established.
